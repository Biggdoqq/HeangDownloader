# Hongguo Downloader (HeangDownloader)

A high-performance desktop application for searching, previewing, and batch-downloading Hongguo short-dramas in 1080p full resolution.

## Features
- Real-time catalog browsing (49,500+ dramas)
- Instant search and link resolution
- Multi-threaded batch video downloader
- High-definition cover and poster extraction
- Built-in video player and download queue
- Seamless Auto-Update powered by GitHub Releases
